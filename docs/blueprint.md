# **App Name**: Metanoia Click: AI Automation

## Core Features:

- Header: Displays a clean and simple header with the Metanoia.Click logo and basic navigation.
- Hero Section: Presents an engaging hero section with a concise description of AI-powered business automation.
- Modules Grid: Organizes business modules in a grid, each with an icon, title, brief description (max 2 lines), and availability status.
- Hover Effects: Provides subtle hover effects on module cards to enhance user interaction.
- Demo Request: Links module cards to detailed demo request forms.
- Financial Analysis: Allows the LLM tool to examine current financial data and automatically generate balances and reports
- Business Intelligence: Employs generative AI to deliver dashboards and insightful data analysis for informed decision-making.

## Style Guidelines:

- Primary color: Muted Blue (#5C87A6) to convey trust and stability.
- Background color: Light Gray (#F5F7FA), providing a clean, professional backdrop.
- Accent color: Teal (#45A69B) to highlight CTAs and interactive elements, adding a touch of modernity.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, and readable aesthetic.
- Utilize Lucide Icons or Heroicons to offer consistent and visually appealing module icons.
- Incorporate generous spacing and whitespace to create an airy, uncluttered design.
- Add micro-subtle animations to enhance interactivity and provide visual feedback.
